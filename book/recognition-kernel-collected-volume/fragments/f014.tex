  -> fixed five-label carrier has no positive-eta path ambiguity

  -> terminal obstruction is a rank-at-most-five seam packet after reduction

  -> do not reopen upstream theorem packets
\end{verbatim}

\begin{verbatim}

\begin{verbatim}
