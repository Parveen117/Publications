\chapter{Cut-Covariance Event Realization Theorem}\label{cut-covariance-event-realization-theorem}}

\hypertarget{purpose}{%
\section{1. Purpose}\label{purpose}}

The remaining source/boundary barrier should not be attacked by treating the
source form and boundary functional as independent objects and then searching
for a decoder after the fact.

Recognition-Seam Calculus permits a stronger order:

\begin{verbatim}
native event lift
-> distinguished boundary recognition state
-> first moment
-> second moment
-> cut covariance
-> target-faithful finite observer.
\end{verbatim}

The source and boundary are then co-generated by one event object. Boundary
square removal is not an inequality guessed from numerics; it is the Gram form
of the memory left after the boundary-recognition line is cut away.

This theorem is universal. It contains no zeta function, prime sum, classical
explicit formula, or RH assumption.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\hypertarget{native-event-cut-datum}{%
\section{2. Native event-cut datum}\label{native-event-cut-datum}}

Let

\[
\mathcal H_{\rm src}
\]

be the positive recognition completion of a native algebraic source core, and
let

\[
\mathcal K_{\rm evt}
\]

be a complete event carrier derived after quotienting the null recognition
seam.

Let

\[
Z:\mathcal H_{\rm src}\longrightarrow\mathcal K_{\rm evt}
\]

be a bounded native event lift. The map \(Z\) must be constructed before the
signed target form is evaluated.

Choose a unit boundary-recognition state

\[
p_\partial\in\mathcal K_{\rm evt},
\qquad
\|p_\partial\|=1,
\]

also generated independently of the desired sign. Define

\[
P_\partial
=|p_\partial\rangle\langle p_\partial|,
\qquad
Q_\partial=I-P_\partial.
\]

The boundary line is the recognized first-moment channel; \(Q_\partial\) is the
cut-memory channel.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\hypertarget{first-moment-second-moment-and-cut-covariance}{%
\section{3. First moment, second moment, and cut covariance}\label{first-moment-second-moment-and-cut-covariance}}

Define the source second moment

\[
\boxed{
S=Z^*Z,
}
\]

the boundary first moment

\[
\boxed{
\ell=p_\partial^*Z,
}
\]

and the cut-memory lift

\[
\boxed{
M=Q_\partial Z.
}
\]

The signed covariance form is

\[
\boxed{
W_{\rm cut}=M^*M.
}
\]

\hypertarget{theorem-3.1-cut-covariance-identity}{%
\subsection{Theorem 3.1 (Cut-covariance identity)}\label{theorem-3.1-cut-covariance-identity}}

The following exact identity holds:

\[
\boxed{
W_{\rm cut}
=S-\ell^*\ell
=Z^*Q_\partial Z
=M^*M
\ge0.
}
\]

\hypertarget{proof}{%
\subsubsection{Proof}\label{proof}}

Since \(P_\partial=p_\partial p_\partial^*\),

\[
\ell^*\ell
=Z^*p_\partial p_\partial^*Z
=Z^*P_\partial Z.
\]

Therefore

\[
S-\ell^*\ell
=Z^*(I-P_\partial)Z
=Z^*Q_\partial Z
=(Q_\partial Z)^*(Q_\partial Z).
\]

The last expression is a Gram form and is nonnegative. ∎

Thus source and boundary are not merely compatible. They are the second and
first moments of one cut-generated event lift.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\hypertarget{infinite-dimensional-cut-square-identity}{%
\section{4. Infinite-dimensional Cut-Square identity}\label{infinite-dimensional-cut-square-identity}}

For every \(f,h\in\mathcal H_{\rm src}\),

\[
\boxed{
\langle h,W_{\rm cut}f\rangle
=
\langle Q_\partial Zh,Q_\partial Zf\rangle.
}
\]

In particular,

\[
\boxed{
\langle f,Sf\rangle
-|\ell f|^2
=
\|Q_\partial Zf\|^2.
}
\]

This is the coordinate-free Cut-Square identity. The finite Lagrange identity

\[
\|c\|^2\|y\|^2-|\langle c,y\rangle|^2
=
\sum_{i<j}|c_i y_j-c_j y_i|^2
\]

is one coordinate realization of the same projection defect.

\hypertarget{event-algebra-covariance-form}{%
\section{5. Event-algebra covariance form}\label{event-algebra-covariance-form}}

Let \(\pi(\mathcal A)\subseteq\mathcal B(\mathcal K_{\rm evt})\) be a represented
native event algebra, and define the state

\[
\omega_\partial(a)
=\langle p_\partial,\pi(a)p_\partial\rangle.
\]

Suppose a linear event assignment \(f\mapsto a_f\) satisfies

\[
\pi(a_f)p_\partial=Zf.
\]

\hypertarget{corollary-5.1-cut-covariance-as-noncommutative-variance}{%
\subsection{Corollary 5.1 (Cut covariance as noncommutative variance)}\label{corollary-5.1-cut-covariance-as-noncommutative-variance}}

Then

\[
\boxed{
\langle h,W_{\rm cut}f\rangle
=
\omega_\partial(a_h^*a_f)
-
\overline{\omega_\partial(a_h)}\,
\omega_\partial(a_f).
}
\]

In particular,

\[
\boxed{
\langle f,W_{\rm cut}f\rangle
=\operatorname{Var}_{\omega_\partial}(a_f)
=\|Q_\partial\pi(a_f)p_\partial\|^2.
}
\]

The algebraic covariance is therefore generated by the cut. It is not imposed
as a positivity axiom.

\hypertarget{the-decoder-is-derived-not-fitted}{%
\section{6. The decoder is derived, not fitted}\label{the-decoder-is-derived-not-fitted}}

Let

\[
\mathcal E
=\overline{\operatorname{Ran}Z}
\subseteq\mathcal K_{\rm evt}
\]

and let \(P_{\mathcal E}\) be its orthogonal projection.

Define

\[
\boxed{
c_{\min}=P_{\mathcal E}p_\partial.
}
\]

\hypertarget{theorem-6.1-canonical-least-energy-decoder}{%
\subsection{Theorem 6.1 (Canonical least-energy decoder)}\label{theorem-6.1-canonical-least-energy-decoder}}

The vector \(c_{\min}\) is the unique vector in \(\mathcal E\) satisfying

\[
\boxed{
\ell f
=\langle c_{\min},Zf\rangle
\qquad(f\in\mathcal H_{\rm src}).
}
\]

Its squared norm

\[
\boxed{
\beta_{\rm cut}
=\|c_{\min}\|^2
=\|P_{\mathcal E}p_\partial\|^2
\le1
}
\]

is the sharp decoder burden.

\hypertarget{proof-1}{%
\subsubsection{Proof}\label{proof-1}}

For \(y=Zf\in\operatorname{Ran}Z\subseteq\mathcal E\),

\[
\langle P_{\mathcal E}p_\partial,y\rangle
=\langle p_\partial,y\rangle
=\ell f.
\]

If \(c\in\mathcal E\) is another representer, then

\[
\langle c-c_{\min},y\rangle=0
\]

for every \(y\in\operatorname{Ran}Z\), hence for every \(y\in\mathcal E\) by
density. Since \(c-c_{\min}\in\mathcal E\), it vanishes. Finally, orthogonal
projection is contractive, so \(\beta_{\rm cut}\le\|p_\partial\|^2=1\). ∎

If \(Z\) has finite-dimensional full column rank and \(S=Z^*Z\) is invertible,
then

\[
\boxed{
\beta_{\rm cut}
=\ell S^{-1}\ell^*.
}
\]

Thus the decoder is not an independently fitted vector. It is the projection
of the boundary-recognition state onto the event range.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\hypertarget{uniform-reserve-and-pointwise-strictness}{%
\section{7. Uniform reserve and pointwise strictness}\label{uniform-reserve-and-pointwise-strictness}}

The decoder burden gives

\[
|\ell f|^2
\le
\beta_{\rm cut}\langle f,Sf\rangle.
\]

Hence, when \(\beta_{\rm cut}<1\),

\[
\boxed{
W_{\rm cut}
\ge
(1-\beta_{\rm cut})S.
}
\]

This is a uniform relative gap.

But a strict uniform reserve is not necessary for pointwise strict positivity.

\hypertarget{theorem-7.1-boundary-line-no-blindness}{%
\subsection{Theorem 7.1 (Boundary-line no-blindness)}\label{theorem-7.1-boundary-line-no-blindness}}

For every \(f\),

\[
\boxed{
\langle f,W_{\rm cut}f\rangle=0
\iff
Q_\partial Zf=0
\iff
Zf\in\mathbb C p_\partial.
}
\]

Consequently,

\[
\boxed{
W_{\rm cut}>0\text{ on nonzero source states}
\iff
\ker(Q_\partial Z)=\{0\}.
}
\]

\hypertarget{proof-2}{%
\subsubsection{Proof}\label{proof-2}}

The Cut-Covariance Identity gives

\[
\langle f,W_{\rm cut}f\rangle
=\|Q_\partial Zf\|^2.
\]

This vanishes exactly when \(Zf\) lies in the boundary line
\(\operatorname{Ran}P_\partial=\mathbb Cp_\partial\). ∎

Therefore an infinite family may have \(\beta_n\uparrow1\) while every finite
packet remains strictly positive. The correct strictness theorem is no
boundary-line blindness, not decimal distance from one by itself.

\hypertarget{target-faithful-observer-derived-after-the-cut}{%
\section{8. Target-faithful observer derived after the cut}\label{target-faithful-observer-derived-after-the-cut}}

Let

\[
T:\mathcal K_{\rm mem}=Q_\partial\mathcal K_{\rm evt}
\longrightarrow\mathbb C^\nu
\]

be a coisometric target observer,

\[
TT^*=I_\nu,
\qquad
P_T=T^*T.
\]

Its cut-observer action is

\[
\mathcal A_\Sigma(T;M)
=\|(I-P_T)M\|^2.
\]

\hypertarget{theorem-8.1-observed-covariance}{%
\subsection{Theorem 8.1 (Observed covariance)}\label{theorem-8.1-observed-covariance}}

If

\[
\mathcal A_\Sigma(T;M)=0,
\]

then

\[
M=T^*TM
\]

and

\[
\boxed{
W_{\rm cut}
=(TM)^*(TM).
}
\]

Thus the finite observed covariance is exact only after zero cut-observer
action has proved target faithfulness.

By the Cut-Variational Minimal Observer Theorem,

\[
\min\operatorname{rank}T
=\dim\overline{\operatorname{Ran}M}
\]

whenever this memory range is finite-dimensional.

\hypertarget{recognition-complete-transfer}{%
\section{9. Recognition-complete transfer}\label{recognition-complete-transfer}}

Let \((Z_n,p_n)\) be transported finite event packets on one recovered carrier,
with

\[
\|p_n\|=\|p\|=1,
\qquad
Z_n\to Z,
\qquad
p_n\to p.
\]

Put

\[
P_n=p_np_n^*,
\qquad
Q_n=I-P_n,
\qquad
M_n=Q_nZ_n.
\]

\hypertarget{theorem-9.1-firstsecond-moment-transfer}{%
\subsection{Theorem 9.1 (First/second moment transfer)}\label{theorem-9.1-firstsecond-moment-transfer}}

The following bounds hold:

\[
\boxed{
\|P_n-P\|
\le2\|p_n-p\|,
}
\]

\[
\boxed{
\|M_n-M\|
\le
\|Z_n-Z\|
+2\|p_n-p\|\,\|Z\|,
}
\]

\[
\boxed{
\|Z_n^*Z_n-Z^*Z\|
\le
(\|Z_n\|+\|Z\|)\|Z_n-Z\|,
}
\]

and

\[
\boxed{
\|M_n^*M_n-M^*M\|
\le
(\|M_n\|+\|M\|)\|M_n-M\|.
}
\]

Also, with \(\ell_n=p_n^*Z_n\),

\[
\boxed{
\|\ell_n-\ell\|
\le
\|Z_n-Z\|
+\|p_n-p\|\,\|Z\|.
}
\]

\hypertarget{proof-3}{%
\subsubsection{Proof}\label{proof-3}}

The rank-one projector estimate follows by adding and subtracting
\(p_np^*\). Next,

\[
M_n-M
=Q_n(Z_n-Z)+(Q_n-Q)Z.
\]

Use \(\|Q_n\|=1\) and the projector estimate. The Gram-form inequalities are
the standard identity

\[
A^*A-B^*B=A^*(A-B)+(A^*-B^*)B.
\]

The first-moment estimate follows from

\[
p_n^*Z_n-p^*Z
=p_n^*(Z_n-Z)+(p_n-p)^*Z.
\]

∎

This theorem is clock-free. The index \(n\) labels directed refinement, not
time. Recovered middle identity and Smriti-tail control are required before the
norm comparisons are lawful.

\hypertarget{non-circularity-rule}{%
\section{10. Non-circularity rule}\label{non-circularity-rule}}

The theorem becomes circular if one defines \(Z\) by taking a square root of the
already desired nonnegative form.

A lawful domain specialization must instead construct:

\begin{verbatim}
Z                     from declared native event amplitudes;
p_partial             from a declared boundary-recognition event;
P_partial and Q_partial from that event state;
T                     from cut-memory action/minimal observer rank;
\end{verbatim}

before evaluating the signed covariance.

The identities

\[
S=Z^*Z,
\qquad
\ell=p_\partial^*Z
\]

must then be verified coefficientwise or by a recognition-complete limit
argument. They may not be installed as definitions of \(Z\) after the desired
form is known.
