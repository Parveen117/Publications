\section{1. Purpose}\label{purpose}}

Stage 3B showed that an actual boundary density in the same chart as an actual
source lower symbol generates a canonical decoder. The remaining question was
how the completed-Weil boundary acquires such a native chart without fitting a
decoder from the terminal sign equation.

The native metric already answers the first half of that question.

In the logarithmic completed carrier, the metric has the graph form

\[

\]

and the full odd boundary Riesz state is

\[

\]

The exact boundary event is therefore not an independently chosen frequency
vector. It is the graph state

\[
\boxed{

}
\]

The second half of the problem is a source-adapter theorem. If the complete
prime--Gamma--diagonal-debt event analysis factors through the graph chart, the

recover only its recognition class modulo the graph-null seam.

The corrected order is

\begin{verbatim}

-> boundary class modulo graph-null memory

\end{verbatim}

This removes the overstrong demand to reconstruct 78,734 individual event
phases one by one.

\hypertarget{metric-graph-boundary-theorem}{%
\section{3. Metric-graph boundary theorem}\label{metric-graph-boundary-theorem}}

\hypertarget{theorem-3.1-boundary-first-moment-from-the-native-graph}{%
\subsection{Theorem 3.1 (Boundary first moment from the native graph)}\label{theorem-3.1-boundary-first-moment-from-the-native-graph}}

For every graph-core state \(f\),

\[
\boxed{
\langle q,f\rangle_{\mathcal H}
=
\langle p_C,J_Cf\rangle_{\mathcal G}.
}
\tag{3.1}
\]

Equivalently,

\[
\boxed{J_C^*p_C=q}
\tag{3.2}
\]

in the graph-form sense. Moreover,

\[
\boxed{
\|p_C\|_{\mathcal G}^2
=
\langle q,M^{-1}q\rangle_{\mathcal H}.
}
\tag{3.3}
\]

\hypertarget{proof}{%
\subsubsection{Proof}\label{proof}}

Since \(Mr=q\),

\[
\begin{aligned}
\langle p_C,J_Cf\rangle_{\mathcal G}
&=
\langle r,f\rangle_{\mathcal H}
+
\langle Cr,Cf\rangle_{\mathcal K}\\
&=
\langle (I+C^*C)r,f\rangle_{\mathcal H}\\
&=
\langle q,f\rangle_{\mathcal H}.
\end{aligned}
\]

Taking \(f=r\) gives (3.3). ∎

The boundary is therefore co-generated by the native metric before any source
inverse or terminal decoder is introduced.

\[
R_{\mathcal H}q=-q,

then

\[
R_{\mathcal H}r=-r,

\hypertarget{proof-1}{%
\subsubsection{Proof}\label{proof-1}}

\[
R_{\mathcal H}r
=M^{-1}R_{\mathcal H}q
=-r.
\]

The graph-state statement follows from the covariance of \(C\). ∎

This is the graph-level origin of the odd boundary zero at the cut.

\hypertarget{recognition-quotient-decoder-theorem}{%
\section{6. Recognition-quotient decoder theorem}\label{recognition-quotient-decoder-theorem}}

The graph analysis can contain event directions that are invisible after
synthesis. Define the graph-null seam

\[
\boxed{
\mathcal N_J=\ker J_C^*.
}
\]

Two graph-event states are recognition-equivalent when their difference lies in
\(\mathcal N_J\).

\hypertarget{theorem-6.1-decoder-class-not-literal-event-equality}{%
\subsection{Theorem 6.1 (Decoder class, not literal event equality)}\label{theorem-6.1-decoder-class-not-literal-event-equality}}

A vector \(c\in\mathcal Y_\Sigma\) decodes \(L\) through \(\Xi=D_\Sigma J_C\)
if and only if

\[
\boxed{
p_C-D_\Sigma^*c\in\ker J_C^*.}
\tag{6.1}
\]

Equivalently, in the recognition quotient

\[
\mathcal Q_J
=
\mathcal G/\ker J_C^*,
\]

one has

\[
\boxed{
[p_C]=[D_\Sigma^*c].
}
\tag{6.2}
\]

\hypertarget{proof-2}{%
\subsubsection{Proof}\label{proof-2}}

For every \(f\),

\[
\begin{aligned}
L(f)-\langle c,\Xi f\rangle
&=
\langle p_C,J_Cf\rangle
-
\langle D_\Sigma^*c,J_Cf\rangle\\
&=
\langle p_C-D_\Sigma^*c,J_Cf\rangle.
\end{aligned}
\]

This vanishes for every \(f\) exactly when the difference is orthogonal to
\(\operatorname{Ran}J_C\), equivalently when it lies in \(\ker J_C^*\). ∎

This theorem is the RSC correction to an overstrong event-orientation demand.
The source adapter may differ from the metric boundary state in a graph-null
memory direction without changing the physical boundary functional.
