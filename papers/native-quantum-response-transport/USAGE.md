# Reading quantum response transport

QRT starts with two positive density observables already present in the
LMD Hilbert space. Exponential filtering prepares a family of normalized
states. Their two centered density responses span a plane inside that
same Hilbert space. The plane's Gram matrix is the covariance H, and its
projected connection is precisely the TVSP connection.

## States, frames and observers

| Object | Meaning | Transport statement |
|---|---|---|
| psi_theta | Normalized filtered base state | Its real-gauge Berry connection vanishes |
| E_i=(X_i-m_i)psi_theta | Actual density response vectors | E*E=H and E*partial_i E=(1/2)partial_i H |
| U | Two-coordinate TVSP transport | U*H(t)U=H(0); generally not Euclidean unitary |
| K | Unitary on the whole existing quantum sector | K E(0)=E(t)U; generated by [Q',Q] |
| Fixed base detector | A retained projection at the starting point | Reads loop rotation relative to that reference |
| Co-transported detector | K Pi K* | Preserves its initial reading on a co-transported state |

For a loop, orthonormal response states rotate by the integrated phase
Phi. A detector along the second response direction gives sin²(Phi).
A detector at 45 degrees gives 1/2+(1/2)sin(2Phi); its displacement from
1/2 distinguishes the orientation for |Phi|<pi/4. The 45-degree angle is
measured in the orthonormal response frame. These bounded projections
act on the actual quantum sector, with no extra tensor factor.

The path is in the two filter-control parameters. Calling the generator
i h[Q',Q] a Hamiltonian does not specify a physical clock or establish
that the original density/current dynamics implements it. Similarly,
response curvature is not yet identified with the old material metric.

## Exact comparison API

From this packet's directory:

```javascript
const R = require('./response_adapter.cjs');
const T = require('../native-tvsp-exponential-transport/transport_adapter.cjs');

const source = R.finiteSource(
  ['1/3', '2/3', '2/3'],
  [[1, 1], [2, 1], [1, 2]],
  3,
  'declared three-atom spectral comparison'
);
const geometry = R.responseGeometry(source);
const path = R.responsePath(source, {a: 1, b: 1, p: 1, q: 2});
const K3 = T.coefficient(path.K, 3);
const U3 = T.coefficient(path.U, 3);
const enclosure = R.continuumBounds();
```

The amplitudes are positive exact rationals whose squares sum to one.
Each atom supplies the two positive observable values. The example uses
the path s=t, v=t². `finiteSource` generates its log-partition precursor
through order N+2 before differentiating to H through order N. The source
E,H and path K,U retain order N; path generators retain order N-1.
This is a finite Taylor certificate, not evaluation of a full exponential
at a finite endpoint. The inherited TLM/TET depth and context checks apply.

`responseGeometry` requires invertible covariance and returns its inverse,
the ambient response projection, source connection and curvature.
`moments(probabilities, points)` computes exact covariance, third cumulants
and the two-dimensional curvature formula without requiring rational
square-root amplitudes. Redundant observable channels can have singular
covariance even when every atom and probability is positive; their inverse
connection is rejected.

The adapter's finite spectral models check the identities. They do not
replace or numerically integrate the actual LMD density law. `continuumBounds`
propagates the separately proved uniform moment bounds using exact rational
arithmetic; it does not compute positive cell probabilities. The actual
unbinned state and its enclosure follow from QRT-T1 and QRT-T4. In particular
the equal-weight center curvature 1/4 is a comparison value, whereas the
actual state's curvature is bounded strictly between 1/8 and 3/8.

## Domains and replay

The written proof establishes full-space unitarity and preservation of
every joint density monomial domain. A bounded instantaneous finite-rank
generator does not imply that K-I has finite rank. Indicator-cell states
are not asserted to belong to the conjugate-current domains.

From the repository root:

```bash
python3.12 papers/native-quantum-response-transport/run.py --check
python3.12 scripts/replay_quantum_geometry.py
```

and symbolic reductions use the frozen native F/Cut and Paninian engines.

controls. Finite comparisons, rational bound propagation and the written
