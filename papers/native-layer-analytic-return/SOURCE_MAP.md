# Source map

| Input | Role |
|---|---|
| LAA-T1 and its SE49 lineage | Unconditional analytic source disk and Cauchy coefficient bound; not an RH assumption |
| LDC retained actual fixture | Existing interval q0 and source coefficients through derivative 19 |
| LWP-T4/T5/T6 | Skew exponential, binomial seed prefix, positive-realization remainder and conditional infinite meaning |

Classical reference: NIST DLMF [4.19.2](https://dlmf.nist.gov/4.19.E2)
for the cosine power series. LAR derives its binomial coefficient bound,
source regrouping and rational remainder explicitly. The classical
Weierstrass compact-convergence theorem is applied to the supplied
majorant. No external numerical library is used.

CI artifact transport uses the pinned
[actions/upload-artifact v4.6.2 commit](https://github.com/actions/upload-artifact/commit/ea165f8d65b6e75b540449e92b4886f43607fa02).
GitHub documents [skip directives](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/skip-workflow-runs)
for output-only import commits. Such an import records the successful
source run; it does not claim a fresh test of the final import commit.
