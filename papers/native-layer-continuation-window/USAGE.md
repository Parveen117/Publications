# Replay LCW-1

From the repository root:

```sh
python3.12 papers/native-layer-continuation-window/run.py --check
python3.12 scripts/replay_quantum_geometry.py
```

Python 3.12 verifies file pins and launches native JavaScript. The
scientific arithmetic stays in the frozen F/Cut and inherited outward
interval engines. Node.js is required. The full-source derivative
evaluation can take several minutes.

`--check` recomputes every fixture, requires exact certificate-byte and
SHA256 agreement, and writes nothing. `--write` regenerates this packet's
certificate after an intentional audited change; it does not update
source pins or any predecessor. The replay never chooses a coefficient
to make the actual source pass a window.

The actual fixture retains all source intervals, both enlarged forms,
four innovations, two normalized positions, the next unexecuted even
window, all available binomial readings and the held-out response.
Written theorems establish arbitrary-order algebra; finite examples do
not substitute for those proofs or establish the universal RH premise.
