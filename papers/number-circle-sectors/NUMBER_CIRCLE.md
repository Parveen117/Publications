## 0. Result

The proposal's elementary pieces are correct and most of them already exist
in the repository (Section 2). Its genuinely useful content is one idea:
**a pair of sectors read in a common frame splits into a common reading
`c`, which a common frame change moves, and a disagreement `d`, which it
does not**. Applied to the actual chiral pair of the 1+1 model this gives a
statement the programme did not have.

**Theorem C (comparison channel of the momentum constraint) [P, using D, E].**
In RGR's setting (X_c = X x X, nu_2^(2), Psi with topology (19)), let
Delta = {(g, g)} be the diagonal subgroup of G_c. By IGQ-T4 it is exactly
the group generated by the smeared momentum constraints D[f]. Let
`rho = chi_+^{-1} o chi_-` be the relative map of the two chiral frames and
`r = rho(0) = chi_+^{-1}(alpha_-)`.

1. `rho` is Delta-invariant everywhere. It is the nonabelian version of the
   disagreement `d`.
2. For every continuous F on S^1, `ell_F(psi) = ∫ F(r) psi dnu_2^(2)` is a
   (19)-continuous, Delta-invariant functional, and F -> ell_F is
   injective. So the momentum-constraint invariant dual is
   **infinite-dimensional**, while the full G_c invariant dual is `C·ell`
   (Theorems U and E).
3. For every N there is a positive Hermitian form on Psi, Delta-invariant in
   each slot, whose physical quotient has dimension N. Under all of G_c,
   the quotient has dimension at most one (Theorem U(d)).
4. Infinitesimally, `ell_F(D[f] a) = 0` for all a in A and real smooth f.
   But if `ell_Phi` (Phi in L^∞(nu_2^(2))) also annihilates every
   `H[f] a`, Phi is a.e. constant. Every nonconstant comparison functional
   is therefore removed by the Hamiltonian constraint, and only by it.

In words, the momentum constraint leaves an infinite-dimensional channel of
relational comparison data between the two chiral frames. The Hamiltonian
constraint is exactly what collapses it to the single channel `ell`. The
"frozen" one-channel physical sector of RGR/Theorem E is not a lack of
relational information at the kinematic-diffeomorphism level. It is the
Hamiltonian constraint acting on that information (Proposition C3 gives the
action explicitly: `rho -> chi_+^{-1} h^{-2} chi_-`).

Not proved: that the Delta-invariants are *exactly* the functions of `rho`
(Conjecture C4). The obstruction is stated precisely.

## 3. Definitions

**Definition 1 (sectored operator).** A sector frame is an ordered,
labelled orthogonal decomposition `H = H_1 (+) ... (+) H_n` with orthogonal
projectors P_i. For an operator M, `M_ij = P_i M P_j : H_j -> H_i`. The
convention is "column = input, row = output", so `M_12` carries sector 2
into sector 1. Composition is `(NM)_ik = sum_j N_ij M_jk`, which is order
sensitive.

Two cautions, both already in the repository. (i) The diagonal blocks do
not determine positivity or spectrum unless M is reduced by the sectors
(MZC-2 §3). (ii) Independent subsystems, such as the two chiral factors of
the model, combine by **tensor product** in the state space
(`H_c = L^2(nu_1) (x) L^2(nu_1)`), not by direct sum. The direct sum
applies to superselection/sign sectors (`H_+ (+) H_-`) and to generator
labels (`Lie G_c = Vect (+) Vect`). The proposal's 4 x 4 block matrix is
meaningful on the latter two, not on independent subsystems.

**Definition 2 (calibrated comparison transform).** Let H_o (observer
sector) and H_x (object sector) be Hilbert spaces and let `V : H_x -> H_o`
be unitary (the calibration: "same units"). Define
`C_V : H_o (+) H_x -> H_o (+) H_o` by

    C_V(o, x) = (c, d),   c = (o + V x)/sqrt 2,   d = (V x - o)/sqrt 2.

For H_o = H_x = K and V = I, C_I = R(-pi/4) (x) I_K with
`R(theta) = [[cos, -sin], [sin, cos]]`.

**Definition 3 (frame-labelled operator).** Let theta -> U(theta) be a
unitary representation of a group Theta on H (here a circle,
U(theta) = exp(theta A)). For an operator M on H and frames alpha, beta,
`M_{beta<-alpha} := U(beta)^{-1} M U(alpha)`. The pair of labels is part of
the object. Products are defined only when the inner labels match.

## 4. Elementary propositions

**P1 (c/d is a rotation by 45 degrees) [P].** With V = I and real scalar
readings:

- `C_I = R(-pi/4)`, `det = 1`, `C_I^T C_I = I`;
- `c^2 + d^2 = o^2 + x^2` (and `||c||^2 + ||d||^2 = ||o||^2 + ||x||^2` in
  general);
- `o = (c - d)/sqrt 2`, `x = (c + d)/sqrt 2`;
- `d = 0` iff `o = x` (iff `Vx = o` in general);
- `C_I^2 = R(-pi/2)` (two comparisons make a quarter turn) and `C_I^8 = I`;
- on the number circle, `c + iota d = e^{-iota pi/4}(o + iota x)`.

*Proof.* `(o+x)^2 + (x-o)^2 = 2o^2 + 2x^2`. The matrix
`(1/sqrt 2)[[1,1],[-1,1]]` is `R(-pi/4)`, which is orthogonal with
determinant one, so its inverse is its transpose, which gives the recovery
formulas. `d = 0` iff `x = o` by the definition. Powers of R are rotations
by sums of angles. Finally `(1 - iota)(o + iota x) = (o + x) + iota(x - o)`
and `(1 - iota)/sqrt 2 = e^{-iota pi/4}`. For general V the map is unitary
because `(o, x) -> (o, Vx)` is unitary and `R(-pi/4) (x) I` is. ∎

Keeping only d loses c: the map `(o, x) -> d` has kernel `{o = x}`
(witness: (1,3) and (5,7) have the same d).

**P1' (behaviour under frame shifts) [P].** For translations of real
readings, the common shift `(o + b, x + b)` changes only c
(`c -> c + sqrt 2 b`) and the opposite shift `(o - b, x + b)` changes only
d. So **d is the invariant of the common frame change** and c is the
invariant of the opposite one. Theorem C is the nonabelian form of this
sentence.

**P2 (calibration is frame-labelled) [P].** Let frame changes act by
unitaries `W_o` on H_o and `W_x` on H_x. The agreement relation `d = 0`,
that is `Vx = o`, is preserved for all pairs iff the calibration transforms
as `V -> W_o V W_x^{-1}`, i.e. V is a frame-labelled operator
`V_{o<-x}`. With a fixed V, it is preserved exactly by the pairs with
`W_o V = V W_x`. For V = I this is the common (diagonal) frame change.

*Proof.* If `Vx = o`, then `W_o o = W_o V x = (W_o V W_x^{-1})(W_x x)`.
Conversely, if a fixed V' satisfies `V' W_x x = W_o V x` for all x, then
`V' = W_o V W_x^{-1}`. ∎

**P3 (composition) [P].** `N_{gamma<-beta} M_{beta<-alpha} =
U(gamma)^{-1} N M U(alpha) = (NM)_{gamma<-alpha}`. For mismatched inner
labels, `N_{gamma<-beta'} M_{beta<-alpha} =
U(gamma)^{-1} N U(beta') U(beta)^{-1} M U(alpha)`, which differs from
`(NM)_{gamma<-alpha}` unless `U(beta')U(beta)^{-1}` commutes past N in the
required way. *Proof:* `U(beta) U(beta)^{-1} = I`. ∎ This is the pair
groupoid of frames. It is standard (change of basis) and is the same rule
the typed presentation already enforces.

**P4 (when one angle suffices) [P].** Let `U(theta) = exp(theta A)` with
`A^2 = -I` on a real space. The following are equivalent:
(i) `M_{beta<-alpha}` depends only on `alpha - beta`;
(ii) M commutes with A;
(iii) when the space is R^2, `M = aI + bA = r U(theta_M)`, the operator
number circle, with `r = sqrt(a^2+b^2)`.
A general real 2 x 2 M needs **two** angles: there are alpha, beta with
`M_{beta<-alpha}` diagonal (real singular value decomposition, [E]), and in
general no single common angle does it.

*Proof.* (ii) => (i): `U(beta)^{-1} M U(alpha) = M U(alpha - beta)`.
(i) => (ii): set `alpha = beta = t`. Then `U(t)^{-1} M U(t) = M` for all t,
and differentiating at 0 gives `[M, A] = 0`. (ii) <=> (iii) on R^2: the
commutant of `A = [[0,-1],[1,0]]` is `span{I, A}`. ∎

So the proposal's "matrix angle" exists exactly for q-type operators. For
every other operator the pair (alpha, beta) carries the extra information,
as the proposal says.

**P5 (the chiral constraint pair is a c/d transform) [P from D].** By
IGQ-T4, `T_eps[f] = -eps Q_eps(f)`, `H = T_+ + T_-`, `D = T_+ - T_-`.

- In moment-map labels, with `o = T_-` and `x = T_+`:
  `(H, D) = sqrt 2 (c, d)`.
- In group-action labels `Q_eps` (which move the frames), with
  `o = Q_-` and `x = Q_+`: `D = -sqrt 2 c` and `H = -sqrt 2 d`.

The inherited opposite chiral sign swaps which constraint is "common".
Geometrically, D generates the common motion of the two frames:
`exp(itD[f]) = U_{(g_f(t), g_f(t))}`. H generates the opposite one:
`exp(itH[f]) = U_{(g_f(t), g_f(-t))}`.

*Proof.* `D = -Q_+ - Q_-` and `H = -Q_+ + Q_-` follow from substitution.
Opposite factors strongly commute (IGQ-T4), so the joint functional
calculus gives `exp(itD) = exp(-itQ_+) exp(-itQ_-)`, and
`U_{g_f(t)} = exp(-itQ(f))` (IGQ (20)). The same holds for H with the sign
of t reversed on the minus factor. ∎

The orientation lesson is that the c/d split is defined only after the
calibration orientation is fixed. This is the proposal's own "same units"
proviso in concrete form.

## 5. The yield: the comparison channel of the momentum constraint

**Lemma C0 (frames) [P from D].** For x = (alpha, sigma) in X put
`chi_x(t) = alpha + I_sigma(t)`. This is an orientation-preserving H^4
circle diffeomorphism (`ERGODICITY.md` Lemma A(a)), x -> chi_x is a
bijection onto those diffeomorphisms, and RGR's action (2) is left
composition:

    chi_{T_g x} = g o chi_x.

*Proof.* Write `c_g = ∫ log g'(chi)`. Then
`e^{sigma + u_g} = e^sigma g'(chi) e^{-c_g}`. By degree one,
`∫ e^sigma g'(chi) = (∫ e^sigma) ∫ g'(chi(t)) chi'(t) dt = ∫ e^sigma`.
Hence `kappa_{sigma+u_g} = kappa_sigma · g'(chi) = (g o chi)'`, and the
base point is `g(alpha) = g(chi(0))`. Conversely, a diffeomorphism phi is
`chi_x` for `alpha = phi(0)` and `sigma = P_0 log phi'`. ∎

Fix the RGR objects X_c, nu_2^(2), Psi with (19), the algebra A, the
generators `B_f^±` (23) and the unitaries U_g [D]. Let
`Delta = {(g, g) : g in Diff_+^∞(S^1)}`. By P5 this is the group of the
momentum-constraint flows. Define

    rho(x_+, x_-) = chi_{x_+}^{-1} o chi_{x_-},    r(x_+, x_-) = rho(0) = chi_{x_+}^{-1}(alpha_-).

**Theorem C [P, using D and E].**

(a) `rho o T_{(g,g)} = rho` everywhere, for every g.

(b) r is continuous on X_c and Lipschitz on each set
`{||sigma_+||_{H^3} <= R}`. Its law under nu_2^(2) has the continuous
density `p(t) = ∫ kappa_sigma(t) dmu_2(sigma) > 0` on S^1.

(c) For F in C(S^1), `ell_F(psi) = ∫ F(r) psi dnu_2^(2)` is
(19)-continuous and Delta-invariant, and F -> ell_F is injective. Hence
`dim (Psi')^Delta = ∞`. More generally `ell_Phi` is Delta-invariant for
every bounded Borel Phi of rho.

(d) For linearly independent F_1, ..., F_N in C(S^1),
`eta_N(psi, phi) = sum_k conj(ell_{F_k}(psi)) ell_{F_k}(phi)` is a
separately continuous positive Hermitian form on Psi, Delta-invariant in
each argument, with physical quotient of dimension exactly N.

(e) For every F in C(S^1), a in A and real smooth f,
`ell_F(D[f] a) = 0`.

(f) If Phi is in L^∞(nu_2^(2)) and `∫ Phi (H[f] a) dnu_2^(2) = 0` and
`∫ Phi (D[f] a) dnu_2^(2) = 0` for all a in A and real smooth f, then Phi
is a.e. constant. In particular, for nonconstant F there exist f and a
with `ell_F(H[f] a) ≠ 0`.

*Proof.*

(a) By Lemma C0, `(g chi_+)^{-1} (g chi_-) = chi_+^{-1} chi_-`.

(b) `chi_+^{-1}(y) = I_{sigma_+}^{-1}(y - alpha_+)`. On
`||sigma||_{H^3} <= R`, `inf kappa_sigma >= m_R > 0` (Lemma A(a)) and
`||I_sigma - I_tau||_∞ <= ||kappa_sigma - kappa_tau||_∞ <= L_R ||sigma - tau||_{H^3}`,
since kappa is a smooth function of sigma into C^0 with bounded derivative
on balls. If `t = I_sigma^{-1}(z)` and `t' = I_tau^{-1}(z')`, then
`m_R |t - t'| <= |I_sigma(t) - I_sigma(t')| <= |z - z'| + L_R ||sigma - tau||`
(circle distances). This gives the Lipschitz bound. Under nu_2^(2),
alpha_- is uniform and independent of (alpha_+, sigma_+). Given x_+,
`alpha_- - alpha_+` is uniform, and `t = I^{-1}(alpha_- - alpha_+)` has
density `I' = kappa_{sigma_+}`. Integrating over sigma_+ gives p.
Positivity holds because each `kappa > 0`. Continuity follows by dominated
convergence (`kappa <= e^{2||sigma||_∞}`, Fernique [E]).

(c) Continuity: `|ell_F(psi)| <= ||F||_∞ ||psi||_{L^1(nu_2)}`, a (19)
seminorm. Invariance: by RGR (11), `R_g^{(1) 1/2} = R_g^{(2)}`, so for
bounded Phi and psi in Psi the change of variables gives
`∫ Phi U_g psi dnu_2 = ∫ (Phi o T_g) psi dnu_2` (the first step of
`ERGODICITY.md` Lemma 1, which uses only quasi-invariance; the same
identity proves (21)). For g in Delta, `Phi o T_g = Phi` when Phi is a
function of rho, by (a). Injectivity: `psi_F = conj(F) o r` is bounded and
continuous, uniformly continuous on (19)-balls by (b), and lies in
L^2(nu_1) and L^1(nu_2). So psi_F is in Psi and
`ell_F(psi_F) = ∫ |F|^2 p dt`, which is positive unless F = 0.

(d) Positivity and Hermitian symmetry are immediate. The null space is
`∩ ker ell_{F_k}`. The quotient is the image of
`psi -> (ell_{F_k}(psi))_k` in C^N, which is all of C^N because the
ell_{F_k} are linearly independent by (c).

(e) Let `U_t^± = U_{g_f(t)}` on the ± factor, and `U_t^Delta = U_t^+ U_t^-`.
By (c), `ell_F(U_t^Delta a) = ell_F(a)`. Write
`(U_t^Delta a - a)/t = U_t^+[(U_t^- a - a)/t] + (U_t^+ a - a)/t`. By RGR
(26), `(U_t^± a - a)/t = t^{-1} ∫_0^t U_s^± B_f^± a ds`. Since
`B_f^± a ∈ A ⊂ Psi` and U^± is strongly continuous on L^1(nu_2) (RGR-T3),
this tends to `B_f^± a` in L^1(nu_2). U_t^+ is an L^1(nu_2) isometry (21)
and is strongly continuous, so the first term tends to `B_f^- a`. Hence
`(U_t^Delta a - a)/t -> (B_f^+ + B_f^-) a` in L^1(nu_2), and since ell_F
is L^1(nu_2)-continuous, `ell_F((B_f^+ + B_f^-) a) = 0`. Finally
`D[f] a = -(Q_+ + Q_-) a = -i (B_f^+ + B_f^-) a` on A (RGR (23), P5).

(f) Since `Q_+ = -(D + H)/2` and `Q_- = (H - D)/2`, the hypothesis gives
`∫ Phi B_f^± a dnu_2 = 0` for all a in A, all f and both chiralities. This
is exactly the identity that Lemma 1 of `ERGODICITY.md` delivers, and the
proof of Theorem E uses the invariance of F only through it. The chaos
endgame then removes the sigma_+ dependence. For the angular step, take
f ≡ 1: then `v_1 = P_0[0] = 0`, the score A_1 vanishes, and
`B_1^+ = -∂_{alpha_+}`. So `∫ Phi ∂_{alpha_+} a = 0` for the product tests
`a = a_1(alpha_+) b(sigma_+) psi'(x_-)`, and Phi has zero distributional
alpha_+-derivative, hence no alpha_+ dependence (Fubini, countable dense
test family). This replaces the finite-rotation step of Theorem E's proof
by its infinitesimal form. Repeat on the minus factor. Then Phi is
constant. For nonconstant F, `Phi = F o r` is not a.e. constant by (b), so
by (e) some H-image is not annihilated. ∎

**Proposition C3 (what the Hamiltonian flow does to the comparison)
[P from D, E].** `exp(itH[f]) = U_{(h, h^{-1})}` with `h = g_f(t)`, and

    rho o T_{(h, h^{-1})} = chi_+^{-1} o h^{-2} o chi_-.

No bounded nonconstant function of rho is invariant under all the finite
H-flows. *Proof.* The formula follows from Lemma C0. The group generated by
Delta and the H-flows contains `(h, h)(h, h^{-1}) = (h^2, e)`. Since
`g_f(t)^2 = g_f(2t)`, it contains every flow on the plus factor, and
likewise on the minus factor. Flows generate Diff_+^∞(S^1), because the
subgroup they generate is normal and nontrivial and Diff_+^∞(S^1) is simple
(Herman–Thurston [E]; the same input as `BRIDGE.md`). So the generated
group is G_c, and an invariant bounded function is constant by Theorem E. ∎

So the Hamiltonian constraint does not merely fail to preserve the
relational data. Through the conjugated left translation by `h^{-2}`, it
acts on rho with no nonconstant bounded invariant. This is the exact,
model-level form of "no conserved relational observable in the vacuum
sector", consistent with the ledger's "vacuum reduced Hamiltonian is
zero".

**Conjecture C4 [C].** (i) `(Psi')^Delta ≅ L^∞(nu_2^(2))^Delta`, the
analogue of Theorem U(a). (ii) `L^∞(nu_2^(2))^Delta` consists exactly of
the sigma(rho)-measurable classes.

Status of each part:

- (i) needs Theorem U's Step 1 (escape to infinity) with Delta in place of
  G_c. That step uses diffeomorphisms acting on one factor; it has not
  been checked for the diagonal.
- (ii) In coordinates `(chi_+, rho)` the Delta action is
  `(chi_+, rho) -> (g chi_+, rho)`. (ii) is then ergodicity of
  `Diff_+^∞(S^1)` on the conditional measures of nu_2^(2) given rho.
  Those measures involve **right** translation of mu_2-typical frames by a
  typical rho. Theorem E concerns left composition with smooth g only, and
  no quasi-invariance of mu_2 under right translation by non-smooth
  diffeomorphisms is available. So (ii) cannot be read off from Theorem E,
  and orbit density would not suffice anyway. In the finite models (W5),
  (ii) holds exactly.
