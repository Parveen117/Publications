# LWP-1 — Wave propagation through source layers

17 October 2026. Continues [LOT-1](../native-layer-observer-transport/THEOREM.md)
in the same actual-source track, with physical interpretation open.

For polynomial-pair states of degree below N carried into depth M,
let d=M-N. The entire wave state is resolved exactly for |k|<=d;
its correlation against an old polynomial-pair observer is resolved
for |k|<=2d. These are different depth requirements. The first
unresolved one-channel return at k=2M-1 changes by exactly
2^(4M-3)h_M on moving from M to M+1.

The cut and channel reflection also define the skew-adjoint
generator L=[P,Z]=(W-W^sharp)/2. Its exponential exp(tL) is unitary.
The new theorem controls its state and correlation errors separately
by factorial tails. This is a source-defined continuous flow; t is a
dimensionless parameter and exp(L) is not asserted to equal W.

For the first-channel constant seed, the exponential return has a
sharper common enclosure, computed from the existing binomial source
readings. At depth10 and t=1 its normalized Taylor remainder radius
is exactly 1/20!. This enclosure applies to every compatible certified
finite extension. Infinite extension still needs all-order source
positivity.
