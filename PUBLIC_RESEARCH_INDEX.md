## Evidence package

Each repository now has `RESEARCH_PROVENANCE.md`, a dated `baseline.json` with file SHA-256 hashes, its checksum, a read-only verifier, and owner-review routing.
The machine-readable [public inventory](provenance/2026-10-26/public-inventory.json) also records published release dates, exact release Git objects, Zenodo creation times, declared archive checksums and independently computed archive SHA-256 hashes where verification succeeded.

Keep these different claims separate:

- **Content identity:** bytes match a digest or Git object.
- **Dated availability:** an external record associates particular archived bytes with a timestamp.
- **Attribution:** author, contributor and source credits identify the work being cited.
- **Scientific status:** a result's assumptions, reproducibility, proof and independent review must be assessed individually.
- **Legal priority:** repository history and DOIs alone do not decide novelty, inventorship or patent priority.

## Owner control and the next archive

Public visibility does not grant visitors write access to the canonical repository. Forks remain separate copies.
`CODEOWNERS` is review routing, not an access lock. GitHub settings must enforce collaborator access, branch/tag protections and immutable new releases.
